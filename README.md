# 掉线补读 (dafeiyu-catchup)

MaiBot 插件：重新上线后自动读取离线期间错过的消息，结合离开时长与时段给出合理的"这段时间去干嘛了"，用当前人设自然补聊一条。

## 功能

- 监听所有会话的活跃时间（持久化，重启不丢）
- 后台探针检测离线窗口：重启/掉线恢复后自动发现错过的消息
- 按**离开时长 + 当前时段**生成合理的去向解释（深夜=睡觉、饭点=吃饭、超一天=出远门……）
- 以当前人设的口吻生成一条自然补聊消息（不逐条复读、不刷屏）
- 同会话冷却防打扰；`dry_run` 模式支持只看效果不真发

## 指令

| 指令 | 说明 |
|---|---|
| `/补读` | 手动触发一次补读（默认回看 120 分钟） |
| `/补读状态` | 查看会话进度 |

## 安装

将本目录放入 MaiBot 的 `plugins/` 文件夹后重启 MaiBot 即可。

## 配置

全部配置项见插件设置面板（冷却、回看窗口、dry_run 等）。
